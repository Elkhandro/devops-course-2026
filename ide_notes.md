# Git в VS Code vs терминал

## Что удобно в VS Code

1. Визуализация diff — сразу видно, что изменилось, без чтения вывода `git diff`.
2. Встроенный редактор конфликтов merge — можно выбирать «оставить моё / их / оба» кнопками.
3. История коммитов в боковой панели — удобно кликать и смотреть изменения.

## Что удобнее в терминале

1. Интерактивный rebase (`git rebase -i`) — в UI его нет, а в терминале он гибкий и быстрый.
